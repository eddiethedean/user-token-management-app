# ETL Pipeline Framework release tracker (ETL-4)

This tracker deliberately records review work separately from the Data Mover GUI release.

| Review item | Evidence to attach | Impact decision | State |
|---|---|---|---|
| Next Beta release notes | Authoritative release URL and version | Compatibility, security, and runtime impact | Awaiting selected train |
| Streaming behavior | Benchmark and backpressure notes | Worker memory and retry changes | Open |
| Python support | Clean install matrix | Supported interpreter range | Open |
| SQL/PySpark extras | Dependency/license report | Optional dependency and image impact | Open |
| Diagnostic contract | Adapter test fixture | UI remediation compatibility | Open |

When a release affects Data Mover, add the authoritative release-note link, date reviewed, impacted
files, migration plan, and rollback plan here. Do not add a delivery date until the platform review is
approved.
